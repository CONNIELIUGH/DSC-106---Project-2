Proposition: Police officers in New York City who have allegations marked as unsubstantiated are more likely to receive a promotion (rank increase) later in their careers.

FOR the Proposition

Design Decisions and Rationale:

  • Using Percentage on the Y-Axis (0): I wanted to convince readers that the statement is true. I used percentages on the y-axis, ranging from zero to a value close to the percentage of officers who were promoted after unsubstantiated cases. This makes that percentage look even higher.
  • Misleading Percentage Labels (2): To support my point, I showed the data in a way that makes it seem like officers with unsubstantiated cases get promoted much more often than those with exonerated or substantiated cases. However, the labels are misleading because they don’t show that there are more unsubstantiated cases overall. The percentages were calculated across all groups combined, instead of within each group separately. If looked closely, all six labels add up to 100%, which is incorrect. Each group (unsubstantiated, exonerated, substantiated) should have its own set of percentages for rank changes that add up to 100%.
  • Title (1.5): Even though I added up all the cases from every group when calculating the percentages, I still used the title “Officer Rank Changes by Allegation Outcome.” A better title would be something like “Overall Percentages of Officer Rank Changes,” but I kept the original title to make the message more convincing.

AGAINST the Proposition

Design Decisions and Rationale:

  • Using counts on y-axis (0): The goal of this visualization is to show that the proposition isn’t necessarily true. By using counts on the Y-axis, where the height of each bar represents the number of cases for a specific combination of rank change and case disposition, it appears that there are more unsubstantiated allegation cases compared to exonerated or substantiated ones. As a result, the three bars under "unsubstantiated" are all taller. This might create the illusion that officers involved in unsubstantiated cases are more likely to receive a rank increase. However, when looking at the proportions labels, the likelihood of different rank changes is actually about the same between exonerated and unsubstantiated cases. The visualization highlights how relying only on raw counts can be misleading without considering relative percentages.
  • Using percentage text labels for bars (2): I decided to add labels for each bar that display the percentage of corresponding rank changes within each respective allegation outcome to address potential confusion caused by the difference in bar heights. The total percentage of labels within each category will add up to 100%. From the graph, it becomes clear that the likelihood or percentage of rank increases for both unsubstantiated and exonerated cases is about the same, even though the bar heights differ. This discrepancy is due to the higher number of unsubstantiated cases compared to exonerated ones.
  • Adding a caption/note (1): To clear up any confusion about the labels above each bar, I decided to add a note that explains what the label represents.

Final Reflection

The most difficult part of this project will be determining the key propositions and deciding which variables to use from the given dataset for the visualization. The dataset I chose, Civilian Complaints Against New York City Police Officers, has around thirty features. It takes some time and effort to understand the description of each feature and to identify trends in the data that I might want to visualize.

Another challenge for me is learning how to make visualizations deceptive. Since I’m using Tableau to generate visualizations, it can be a bit harder to modify them in ways that create a specific effect. I spent time exploring different features and tools in Tableau and discovered an interesting deceptive technique by changing the way percentages are calculated (e.g., using "Pane across" vs. "Table across").

I also have to modify the dataset a little, because I want to explore whether having an allegation case affects an officer’s career. I added a new column showing the change in rank before and after the allegation. This column has three possible values: increase, decrease, or no change. Creating this new feature helped me show a clearer connection between allegations and career impact.

I would define ethical analysis and visualization as using data honestly without making changes that alter its overall meaning and designing charts with labels and axes that aren’t misleading. I personally think that the title of a visualization plays a very important role. If the title doesn't match what the visualization shows, then it spreads misinformation and becomes misleading. For a design decision to be ethical, it should not distort the original data, and the labels used must accurately reflect what’s being shown.
